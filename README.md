# Perfect Match — Love Gifts

An interactive romantic surprise: a Perfect Match card game, a vinyl song player,
a typed love letter, and a tulip bouquet with little notes. Everything can be
personalised (photos, letter, notes) from the **Personalize** button; changes
are stored in the browser's localStorage.

## Run locally

Prerequisite: Node.js

```
npm install
npm run dev      # http://localhost:3000
npm run build    # production build in dist/
npm run lint     # type-check
```
